# When Creation Changes — Prototype (full three-set)

## Quick start

1. Open `index.html` in any modern browser. Double-click works; no server required.
2. Click **Begin**. Walk through Set 1, then Set 2, then Set 3, then the final cross-set summary.
3. The flow per set: Judge → Reason → Method → Judge again → Reason → Structure → Judge once more → Reason → Reflect.

If media files are missing for a given work, the prototype shows a styled placeholder with the expected file path. The flow still works for testing without the media.

## What's implemented

- Full three-act flow with multi-stage judgment for each set.
- Three sets (Image, Audio, Video) using a shared scene template populated from data.
- Audio playback with custom minimal controls (play/pause toggle, time display, progress bar).
- Video playback with click-to-play overlay; pauses on scene transition.
- All media auto-pause when the user navigates away or selects a work.
- Per-set Reflect with judgment timeline (initial → after method → after structure) and aggregate display.
- Final cross-set summary: 3×3 grid of all nine picks, with cells highlighted where judgment changed, plus three summary stat lines.
- Closing manifesto (4 short paragraphs in the final scene).
- Fully responsive (stacks on mobile).

## Browser support

Tested on recent Chrome, Safari, Firefox. Custom audio/video controls use standard HTML5 APIs. Google Fonts and Pretendard CDN need internet access on first load.

## Pacing controls (in `index.html` JavaScript)

- `rowInterval` (line 700-ish): time between structure-reveal rows. Default 1000ms. Lower = faster.
- `startDelay` (line 700-ish): pause before first structure line. Default 500ms.
- Method reveal stagger: 500ms after scene entry, all three appear together.
